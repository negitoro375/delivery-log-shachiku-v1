## 利用者の追加・削除

ログインできるGoogleアカウントは、`index.html` の `ALLOWED_HASHES` で決めています。
公開リポジトリなので、**メールアドレスそのものはコードに書かず**、SHA-256に変換した値だけを置いています。

- 追加：アドレスを小文字にして前後の空白を取り、SHA-256（16進数・64文字）に変換した値を `ALLOWED_HASHES` に1行足す。コメントは `// 利用者5` のように番号だけにする（名前やアドレスは書かない）
- 削除：その人の行を消す
- Claude Code / Codex に頼むときの例：「〇〇@gmail.com をログインできるように追加して。アドレスはコードやコミットメッセージに書かず、ハッシュだけ足して」

記録データは各端末のブラウザの中（localStorage）にあり、この一覧を変えても消えません。
